Projeto iniciado
https://github.com/VILLA-1984/projeto1-Bimestre

1 - clonar o projeto
	git clone
2 - Atualiza as dependências
	composer install
	npm install
3 - Gerar chave de criptografia de acesso ao servidor
	php artisan key:generate
4 - Gerar a base de dados
	php artisan migrate
5 - Subir o servidor local
	php artisan serve
